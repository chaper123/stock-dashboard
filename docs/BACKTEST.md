# 買點規則回測

> 2026-10-29。研究用：engine、排程、規則參數都沒有改。程式在 `backtest/`，資料在 `backtest/data/`（不進 git，`py -3.14 backtest/fetch_data.py` 重抓），結果在 `backtest/out/`（不進 git，`py -3.14 backtest/sim.py` 重跑，約 30 分鐘）。
> 所有結果都是依自訂規則的歷史模擬，不是投資建議。

## 1. 結論

**單位**：「XIRR 差」是年化資金加權報酬率相差幾個**百分點／年**（不是累積）；「期末差」才是期末總值相差的累積百分比。樣本外（2023-10-30～2026-10）是重新從 6,000 起算的另一段模擬。

| 比較（對各自的定期定額） | 全期間 XIRR 差 | 樣本內 | 樣本外 | 期末差（全期間） |
|---|---|---|---|---|
| 台股 A 現行規則 | −0.02 | −0.00 | −2.79 | −0.2% |
| 台股 B ＋日 KDJ 確認 | −0.80 | −0.91 | −29.66 | −8.9% |
| 台股 C ＋週 KD 確認 | −1.19 | −1.20 | −55.60 | −12.9% |
| 台股 D ＋景氣燈號 | −0.01 | +0.01 | −2.70 | −0.1% |
| 美股只用 SPY　A | +0.02 | +0.06 | −4.69 | +0.2% |
| 美股只用 SPY　B | −1.09 | −1.13 | −14.03 | −11.7% |
| 美股只用 SPY　C | −12.65 | −10.67 | −16.96 | −74.1% |
| 美股五檔　A（對每月輪流買一檔） | +2.84 | +3.06 | −3.70 | +38.7% |
| 美股五檔　B | +2.45 | +2.12 | −7.42 | +32.5% |
| 美股五檔　C | −1.82 | −1.85 | −11.89 | −19.0% |

1. **現行規則（A）和定期定額幾乎一樣**。台股全期間差 −0.02、SPY 單獨 +0.02 個百分點／年；平均成本台股高 0.2%、SPY 低 1.3%。原因是入金小、買區常出現（0050 樣本內 41% 的交易日在買區，SPY 22%），每次又用掉資金池 25%～60%，錢通常幾天內就投完，行為接近「晚幾天的定期定額」。樣本外三年是大多頭，A 等回檔的那幾天都買在較高的價位，所以兩邊都輸定期定額（台股 −2.79、SPY −4.69）。
2. **止跌確認（B、C）在每個市場、每段期間都比 A 差**，樣本外差更多。確認條件很少成立（台股 B 全期間只有 43 天、C 21 天；SPY 的 C 19 年只買過 1 次），現金一放就是好幾年（台股 B 平均現金 18%、最長 795 天沒買；C 最長 1,448 天）。平均成本有時比較低（台股 C −6.8%），但錯過的漲幅遠大於省下的成本。最大回撤比較小（台股 B −28.5% 對定期定額 −52.0%），只是因為大部分時間抱著現金。
3. **景氣燈號（D）對結果幾乎沒有影響**（對 A：全期間 +0.01、樣本外 +0.09 個百分點／年；買進次數從 1,579 減為 1,428）。A 的錢本來就很快投完，藍燈升一級只是讓錢早幾天投出去；紅燈把上限降到 40% 只影響深度買區那幾天。2008～2026 有 864 天藍燈、1,272 天黃藍、570 天紅燈。
4. **訊號品質（買進訊號後的報酬 vs 隨機日期）**：
   - 0050：在買區當天買，之後 250 個交易日平均 +8.1%，隨機日期 +9.8%（樣本外 46.4% 對 54.7%）——買區沒有比較好的進場點。
   - SPY：買區比隨機日期好一點（250 日 12.8% 對 10.8%，樣本外 19.8% 對 18.1%，自助抽樣 p＝0.00、0.03）；B 的確認日更好（16.2% 對 10.8%），但樣本內只有 29 天。
   - NVDA、AAPL：買區明顯比隨機日期差（NVDA 250 日 36.1% 對 61.7%），長期上漲的個股越跌越常落在買區。
5. **美股五檔的比較不能當成「擇時」的證據**：A 贏輪流定期定額 2.84 個百分點，主要是錢分給哪一檔不同（A 把 29% 放在 TSLA、只有 11% 在 SPY；定期定額各約 21%），以及 NVDA 的平均成本低 30%；樣本外就變成輸 3.70。乾淨的擇時比較看「SPY 單獨」那一列。五檔的 XIRR（約 40%）是事後挑出贏家造成的，絕對數字沒有意義。

**建議**：B、C、D 都**不建議**放進影子模式。B、C 擋掉買進的代價（現金閒置）在台股、SPY、美股五檔、樣本內外都一致大於好處；D 沒有可量測的差異。KDJ 維持在網站 K 線頁當參考即可，不要變成擋買條件。
10/28 那種「已跌破第一買區下緣、程式仍給第一買區金額」的情況，歷史上加止跌確認並沒有讓結果變好。
如果之後還想研究，值得先寫好假設、再做影子測試的方向（這次都**沒有**測，避免在同一份資料上反覆調參數）：
- 只把 KDJ 確認當成 SPY／VOO 的「加碼提示」，不擋原本的金額（SPY 是唯一買區與確認日都比隨機好的標的）。
- 個股（NVDA、AAPL）的買區定義是否需要不同（訊號比隨機差，但本次回測沒有估值閘門，實際排程會擋掉很多）。
- 現行規則與定期定額差不多，規則的主要價值是紀律與不追高，而不是報酬；要不要簡化成定期定額由使用者決定。

## 2. 比較的版本

| 版本 | 內容 | 做法 |
|---|---|---|
| A | 現行規則 | 台股 engine-v1.0 `monitor.py`、美股 engine-v1.1 `monitor_us.py`，每個交易日直接呼叫 engine 的 `main(cfg)`（日線以記憶體中的 CSV 餵入，不重寫規則） |
| B | A＋日 KDJ(9,3,3) 止跌確認 | engine 判定在第一／第二／深度買區時，當天 K 由下往上穿過 D（前一根 K ≤ D、這一根 K > D）且 K < 30 才給金額，否則當天改成等待。KDJ 算法與網站 K 線頁（c5400e0）相同 |
| C | A＋週 KD 止跌確認 | 同 B，用週線（週五為一週）；本週還沒結束時用到當天為止的資料（測試確認等於只用那天以前的日線重算週 K 線） |
| D | A＋國發會景氣對策信號（只限台股） | 當天以前已發布的最新燈號為藍或黃藍、且在買區 → 升一級（深度買區不再升，金額照 engine 比例重算）；紅燈 → 單次上限 60% 改 40% |
| 基準 | 定期定額 | 入金當天（遇假日順延到下一個交易日）把現金全部買進；美股五檔是每月輪流買一檔，另列只買 SPY |

B、C、D 都是包在 engine 外面：替換記憶體裡模組的 `decide`（D 另外在紅燈日暫時改那份模組的 `run_cap`），`engine/` 檔案不動，執行前核對 SHA-256（engine-v1.0、v1.1）。參數在跑之前就定好，全期間沒有調整過。

## 3. 模擬方式與假設

| 項目 | 台股 | 美股 |
|---|---|---|
| 標的 | 0050（代表 009816、00981A） | SPY（代表 VOO）、GOOGL、NVDA、AAPL、TSLA（上市滿 252 個交易日才納入，TSLA 約 2011-07 起）；另做只用 SPY 的單獨模擬 |
| 判定時點與價格 | 排程 10:17：engine 用到前一天收盤的 252 根日線，判定價＝當天開盤 | 排程 09:20：用到前一個美股交易日收盤的 252 根日線（market-data 美股只保留一年，同長度） |
| 成交價 | 當天開盤 | 下一個交易日開盤 |
| 資金 | 起始 6,000、每月 6 日 3,000，未用完累積；台股與美股各自獨立模擬（上限 60%／40% 由 engine 處理） | 同左 |
| 下單限制 | 整股（零股），手續費 0.1425%（最低 1 元） | engine-v1.1：每筆最低 50 美元、圈存 3%（換算美元時扣掉）；台幣扣款＝美元×當天台銀即期賣出；不計手續費 |
| 未套用的閘門 | 溢價（沒有 0050 歷史淨值）、事件旗標 | 估值閘門關閉（歷史 Forward PE 拿不到，估值固定為「合理」＝不降級、不禁買）、事件旗標 |
| 匯率 | — | 台銀美元即期賣出（FinMind，與排程同來源），匯率濾網照 engine |
| 股利 | 現金另外累積、不再投入（和帳本的可用資金公式一致），期末計入總值；不計所得稅與二代健保 | 同左，扣 30% 預扣稅，用當天匯率換台幣 |
| 期間 | 全期間 2008-01-02～2026-10-28；樣本內到 2023-10-27；樣本外 2023-10-30 起重新從 6,000 開始 | 同左，到 2026-10-26（最後一天的委託要隔天成交） |

指標：
- **XIRR**：入金是現金流出、期末總值（持股市值＋未投入現金＋累積股利）是流入，算年化資金加權報酬。
- **平均現金比例**：每天「未投入現金 ÷ 總值」的平均。**最長閒置**：兩次買進之間（含開始到第一次、最後一次到期末）最長的日曆天數。
- **最大回撤**：扣除入金影響的時間加權淨值的最大跌幅（含現金）。
- **買進訊號後報酬**：訊號當天（台股）或隔天（美股）開盤買進，到第 60／120／250 個交易日收盤的報酬（只看價格、不含股利）；隨機日期是同期間所有交易日；p 是自助抽樣 2,000 次中，隨機抽同樣天數的平均報酬 ≥ 訊號平均的比例。A 的訊號＝在買區（台股含趨勢起始倉），B、C 是確認後的買區天數；D 的訊號天數和 A 相同，不另列。

## 5. 限制

- **替代標的**：0050 同時代表 009816 與 00981A；00981A 是主動式 ETF、波動與持股不同，結論不一定適用。溢價閘門沒有套用。
- **美股估值閘門關閉**：實際排程常把 TSLA、AAPL（及 SPCX）判成「明顯偏貴」而禁買，回測買得比實際多。
- **事後挑選的美股名單**：NVDA、TSLA、GOOGL、AAPL 是 2026 年才知道的贏家，五檔的絕對報酬（XIRR 約 40%）嚴重高估；只能比較同一名單內的版本差異，擇時效果看 SPY 單獨。
- **景氣燈號是最新修正值**（不是當時公布的初值，常見 ±1 分、偶爾跨過燈號門檻），發布日多半是估計的（次月 30 日、2 月用月底、遇週末往後延、國定假日沒考慮；偏保守，幾乎不會早於實際發布），所以 D 仍有些微前視偏誤。
- **成交價近似**：台股用開盤價代表 10:17 的盤中價，美股用隔天開盤；實際成交價不同。
- **成本與稅**：美股不計手續費，台股股利稅與二代健保沒算；股利不再投入（兩邊同樣處理）。
- **訊號報酬的 p 值偏樂觀**：訊號天數彼此相鄰、持有期間重疊，獨立性不足；只當描述用。
- **只測了指定的確認規則**（穿越當天且 K < 30）。放寬成「最近 N 天內穿越過」之類的變化沒有測，避免在同一份資料上反覆嘗試。
- **期間**：2008～2026 只有一次大空頭（2008）與一段很強的樣本外多頭（2023～2026），結果和市場狀態有關。
