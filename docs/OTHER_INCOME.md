1. **新分頁「其他入帳」**（放在「定投金額」後面，凍結第 1 列）。欄位：

   | 欄 | 名稱 | 說明 |
   |---|---|---|
   | A | 入帳日 | 錢進到口袋錢包的日子（YYYY-MM-DD） |
   | B | 市場 | 台股／美股；手續費折抵兩邊都有時寫錢包上的說明，網站不用這欄算錢 |
   | C | 代號 | 配息填代號；手續費折抵空白 |
   | D | 類型 | 配息／手續費折抵（只能這兩種） |
   | E | 原幣金額 | 知道才填（例如美股配息的美元）；可以空白 |
   | F | 幣別 | TWD／USD，跟 E 一起 |
   | G | 台幣金額 | **實際進錢包的台幣**（美股配息已扣預扣稅；台股配息已扣二代健保與匯費），網站只用這欄 |
   | H | 計入資金池 | 入帳日在基準日（含）以後填「是」，以前填「否」 |
   | I | 來源 | 例如「口袋錢包帳務明細」 |
   | J | 備註 | 例如錢包上的原文「4 月台 3 美 2 折抵」 |

3. **「設定」分頁**：最下面加一列 `基準日後其他入帳（NT$）`，B 欄公式 `=SUMIFS('其他入帳'!G:G,'其他入帳'!H:H,"是")`，C 欄說明
   「只計「其他入帳」分頁計入資金池＝是的列（配息、手續費折抵）」。可用資金那一列（目前第 15 列）的公式最後加上這一格，說明改成

4. **發布**：網站讀的是帳本「發布到網路」的 CSV（`config.js` 的 `sheetCsv(LEDGER_PUB, gid)`）。確認「其他入帳」也在發布範圍（整份文件發布、而且有勾自動重新發布就會包含；只發布部分分頁就要把它加進去）。新分頁的 gid（sheetId）由主 session 用唯讀連接器讀，填進網站設定。

## 2. 網站

全程繁體中文；版面沿用現有樣式；不合併、不 push、不改 `sw.js` 的 `VERSION`；新檔加進 `SHELL_FILES`。

1. **`config.js`**：`SOURCES.ledger.income = sheetCsv(LEDGER_PUB, INCOME_GID)`，`INCOME_GID` 先放 `null`（主 session 拿到 gid 後補上）。`null` 時當成「還沒設定」。
2. **`data.js`**：
   - `loadIncome()`：回傳 `[{ row, date, market, code, kind, amount, currency, twd, inPool, source, note }]`，只留日期格式對、類型是「配息」或「手續費折抵」的列。
     來源沒設定（gid 是 null）回傳 `{ configured: false, rows: [] }`；讀不到丟 `DataError`，由呼叫端處理。（回傳形狀實作可以調整，寫進規格回報。）
   - `loadSettings()` 多讀「基準日後其他入帳」→ `incomeSince`（沒有這一列就是 null）。
3. **`cash.js`**：
   - `cashTable({ settings, trades, income })`：`income` 是 `loadIncome()` 的結果（讀不到傳 null）。計入資金池＝是的列逐筆列出、加總；任何一列台幣金額讀不到，合計是 null（不補 0）。
     期末＝期初＋入金－買進＋賣出＋其他入帳。`income` 是 null（讀不到）→ 期末 null、missing 列「其他入帳」；還沒設定 → 其他入帳當 0，回傳 `incomeConfigured: false`。
     多回傳 `income`（合計）、`incomeRows`、`ledgerIncome`（設定的 incomeSince）、`incomeDiff`。
   - `assetTrend`：可用資金在每筆計入資金池的其他入帳的入帳日加上那筆金額（入帳日不是交易日就算在下一個交易日）。
4. **資產頁「現金與投入」卡**：在賣出後面加一行「＋其他入帳（配息、手續費折抵）」，金額與逐筆明細（同買進、賣出的展開寫法）；算式文字改成含其他入帳；
   跟帳本比對多一項 `incomeDiff`。還沒設定時寫一行小字「帳本的「其他入帳」分頁還沒接上」。
5. **`perf.js`（組合績效）**：
   - `computePerf` 多吃一個 `income`（預設空陣列；`loadPerformance` 讀不到或沒設定就用空陣列並標 `incomeKnown: false`）。
   - 算進去的列：**美股配息**與**手續費折抵**（計入資金池是或否都算，因為報酬是從第一筆買進算起）。**台股配息不算**：台股 ETF 的現金股利已經用
     market-data 的除息資料在除息日算過，再加會重複。
   - 每天多一個欄位 `other`（那天入帳的金額合計，入帳日不是格子裡的交易日就算在下一個交易日）；單日報酬分子、累計損益、XIRR 的現金流都跟 `div` 一樣加上 `other`。
     `div` 的意思不變（台股 ETF 除息的現金股利）。
   - 註解與資產頁的說明文字改成：「含已領的台股 ETF 現金股利（稅前）、美股配息（扣稅後實收）與手續費折抵」。資產頁每日損益與報酬日曆的算式跟著加 `other`。
6. **不做**：Apps Script 與記帳頁不改（「其他入帳」由使用者在試算表記）；持倉頁不改；晨報不改；台股配息的實收與網站算的稅前金額不做比對。

## 3. 驗收

- 測試（照現有測試頁的寫法，`cash`、`perf`、`assets` 補案例，或新增一頁）：
