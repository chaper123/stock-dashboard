## 2. 純函式：`site/js/realized.js`（新檔）

`realizedPnl(trades, { refFx } = {})`。`trades` 是 `loadTrades()` 的結果（沖銷的一對已經拿掉）；`refFx(date)` 回傳不晚於那天的
美元兌台幣中間價（同 `portfolio.js` 的 `fxOn`），沒有就是 null。

- 只看「買進」「賣出」、股數 > 0 的列。依 `市場:代號` 分組；組內依日期排序，同一天依帳本列號（`row`）。
- **平均成本法，全部用台幣**（跟 `twdCostBasis` 同一種算法）：
  - 買進的台幣成本：台股＝`twd ?? settle ?? 股數×成交價＋手續費`；美股＝`twd`，沒有就 `(settle ?? 股數×成交價) × fx`（帳本的
    成交匯率），再沒有用 `× refFx(日期)` 並標**參考匯率**；連參考匯率都沒有，這一檔回報錯誤「MM/DD 的買進沒有台幣金額，也查不到當天匯率」。
  - 賣出拿回的台幣：台股＝`twd ?? settle ?? 股數×成交價－手續費－交易稅`；美股同上（`twd` → `settle × fx` → `× refFx`）。
  - 台股用到「股數×成交價」那一種（`twd`、`settle` 都空白）就標**估算**。
- 每筆賣出：`賣出成本＝賣出前總成本 × 賣出股數 ÷ 賣出前股數`；`損益＝拿回的錢－賣出成本`；`報酬率＝損益 ÷ 賣出成本`。
  賣出後總成本、股數同比例減少；股數歸 0（容許 1e-9）時總成本也歸 0，下一筆買進重新開始一段持有。
- 賣出股數超過當時持有：這一檔回報錯誤「MM/DD 賣出 N 股超過當時持有的 M 股」，這一檔不算，其他檔照算（不要整個丟例外）。
- 每筆賣出回傳：`{ date, market, code, shares, since, days, proceeds, cost, pnl, pct, est, ref, closed }`
  - `since`：這段持有的第一筆買進日（上一次股數歸 0 之後的第一筆買進），`days`＝`since` 到賣出日的日曆天數。
  - `est`：這段持有裡有任何一筆買進，或這筆賣出本身用了估算。`ref`：用到參考匯率。`closed`：賣完後股數是 0。
- 回傳 `{ rows（新到舊）, total, cost, proceeds, pct（cost 是 0 時 null）, est, ref, errors: [{ code, message }], open: { "市場:代號": { shares, cost } } }`。
  `open` 是還沒賣掉的部分（測試用來對 `twdCostBasis`）。
